# 📦 ServiceField - Plateforme de gestion des services sur le terrain

Projet réalisé dans le cadre de mon **stage d’été chez L-mobile** (01 juillet – 26 septembre 2024).  
Cette application permet de gérer efficacement les articles, les types d’articles, les fournisseurs, les utilisateurs, et les interventions sur le terrain.

🔗 Repo GitHub : [ServiceField](https://github.com/houyembn/ServiceField/tree/Articles)

---

## 🚀 Objectif du projet

Développer une application web complète permettant à l’entreprise :
- De gérer ses ressources (articles, utilisateurs, types, etc.)
- De centraliser les opérations terrain
- D'améliorer la traçabilité des interventions techniques
- De faciliter l'administration grâce à une interface intuitive

---

## 🛠️ Technologies utilisées

### Backend – ASP.NET Core
- Architecture MVC
- API RESTful
- Entity Framework Core
- SQL Server

### Frontend – React.js
- React Router DOM
- Axios
- Bootstrap
- Vite.js

### Autres outils
- Git / GitHub (Branches, Pull Requests, collaboration)
- Visual Studio / VS Code
- Jira, Scrum (sprints, daily standups)
- CI/CD en local (automatisation de build/test)

---

## ✨ Fonctionnalités principales

### 🔧 Gestion des Articles
- CRUD complet sur les articles
- Validation des champs (barcode, prix, unités, etc.)
- Système de lookup : types d’articles (ItemTypes)

### 🔐 Gestion des utilisateurs
- Page de connexion et d’inscription (SignIn / SignUp)
- Backend prêt pour l’authentification étendue

### 📊 Interface administrateur
- Navigation via sidebar
- Fiches détaillées par article
- Actions : éditer / supprimer
